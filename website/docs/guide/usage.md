# 界面与功能

SeedVR2-lite 提供完整的 Web UI（FastAPI + Jinja2 + HTMX），包含以下页面：

## 修复工作台

- 上传单张图片或单个视频，选择模型 / 精度 / 放大倍率等参数
- 「VRAM 预检 & 推荐参数」按钮：根据输入分辨率、模型大小和可用显存自动推荐最优参数组合
- 「开始修复」后实时显示进度、阶段日志与显存占用
- 完成后支持**修复前 / 修复后对比滑块**，可水平 / 垂直对比、缩放查看

## 批量修复

- 输入文件夹路径 → 扫描 → 批量加入队列 → 一键开始
- 支持**断点续跑**：每处理完一个文件自动保存 checkpoint（`data/checkpoints/`），
  崩溃或关闭后重启可恢复，已完成文件通过路径+大小+修改时间指纹跳过

## 历史记录

- 模拟 SQLite 历史库，支持搜索、按类型 / 状态筛选、表格 / 卡片视图切换

## 系统状态

- 实时 GPU 利用率、显存占用、温度、功耗、系统内存
- 模型注册表（各模型大小、精度、加载状态）
- **VRAM 估算计算器**：选择模型 / 分辨率 / 帧数 → 估算显存 → 给出推荐参数组合
- 估算公式：模型基线显存 + 分辨率额外开销 + 视频帧缓冲；推荐逻辑 FP16 → FP8 → FP8+BlockSwap 逐级回退

## 设置

- 深色 / 浅色主题切换
- 模型来源模式（shared / portable）
- 界面语言（5 种：中 / 繁 / 英 / 日 / 法）
- 断点续跑开关、FAQ

## 国际化（i18n）

- 翻译文件采用 JSON 格式，位于 `app/integrated_app/locales/`
- 支持五种语言：中文（zh）、繁体中文（zh-TW）、英文（en）、日文（ja）、法文（fr）
- 三层回退机制：指定语言 → 英文（en）回退 → key 本身（兜底）
