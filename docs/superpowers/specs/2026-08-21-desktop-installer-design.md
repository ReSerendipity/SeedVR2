# SeedVR2-lite 桌面发行方案设计（EXE 安装包）

> 状态：已确认（含微调）
> 日期：2026-08-21
> 适用范围：Windows 新手用户零门槛分发

## 1. 背景与目标

SeedVR2-lite 当前通过 `install.bat` + `start.bat` + 手动下载模型交付，对新手门槛高
（需装 Python、跑命令行、处理 CUDA/依赖/模型放置）。本方案目标是：

- 用户从 GitHub Release 下载**单个 EXE**，双击按向导安装，桌面出现快捷方式；
- 双击快捷方式后自动完成环境检测、依赖安装、校验、模型引导、冒烟测试，
  最终**自动在浏览器打开 `http://127.0.0.1:7870`** 开始使用；
- 全部过程有及时的进度提示、帮助说明、失败重试与校验，不给新手留"黑盒"。

## 2. 关键约束（硬性事实）

| 项 | 值 | 影响 |
|---|---|---|
| GitHub Release 单附件上限 | 2 GiB（官方硬限制，LFS 不可突破） | 依赖中 **torch CUDA 单 wheel ~2.5GB 超限**，不能附赠在安装包里，需首启自动下载 |
| 依赖体积 | torch ~2.5GB（唯一大头）；其余（torchvision/torchaudio/opencv/numpy/fastapi 等）合计 ~400-500MB | 小依赖可**内置进安装包**，torch 家族首启自动下载 |
| 模型权重 | 3B ~20GB / 7B ~40GB | 只能引导用户手动下载 |
| GPU | 仅支持 NVIDIA CUDA，不支持 CPU 推理 | 启动时必须检测并提示 |
| 便携 Python | WinPython ~150-300MB | 可内置，单文件仍远低于 2GB |

因此发行姿态：**GitHub Release 只放安装包（含 Python+应用+小依赖）；torch 首启从官方源自动装；模型引导手动下载。**

## 3. 总体架构

```
┌──────────────────────────────────────────────────────────┐
│ GitHub Release 附件                                        │
│   SeedVR2-Setup-<ver>.exe   (~700MB-1GB)  ← 唯一下载物     │
│   内含：便携 Python + 应用本体 + 启动器 + 全部小依赖        │
│   SHA256SUMS + SHA256SUMS.gpg（GPG 签名，复用现有流水线）    │
└──────────────────────┬────────────────────────────────────┘
                       │ 双击
┌──────────────────────▼────────────────────────────────────┐
│ Inno Setup 安装向导（3 步：路径→安装→完成）                 │
│   安装到 %LOCALAPPDATA%\SeedVR2-lite（无需管理员权限）       │
│   创建桌面快捷方式 → 安装完成自动启动                       │
└──────────────────────┬────────────────────────────────────┘
                       │ 每次双击桌面快捷方式
┌──────────────────────▼────────────────────────────────────┐
│ SeedVR2.exe 启动器（PyInstaller --windowed，~50MB，无控制台）│
│   ① 本地引导服务起在 localhost:7871                        │
│   ② 浏览器打开引导页（8 步向导）                            │
│   ③ 仅 torch 家族在线安装（小依赖已内置），支持断点/换源     │
│   ④ 步骤状态持久化 .setup_state.json（幂等/断点续装）        │
│   ⑤ 全部就绪后启动 app/clean_launch.py（不改动）→ 跳转 7870  │
└───────────────────────────────────────────────────────────┘
```

**新增 `launcher/` 目录**（独立于现有 `app/`，零侵入，不改任何现有代码）：

- `launcher_main.py` — PyInstaller 窗口入口（无控制台）
- `bootstrap_server.py` — 引导页本地服务（Python stdlib http.server，零额外依赖）
- `setup_state.py` — 步骤状态持久化（`.setup_state.json`，断点续装）
- `static/` — 引导页前端（沿用项目设计语言：白底、无装饰性滤镜）
- `installer.iss` — Inno Setup 打包脚本
- `workflow/` — GitHub Actions 打包发布脚本（扩展现有 release 流水线）

## 4. 用户旅程（8 步向导）

| 步 | 环节 | 关键行为 | 校验门禁 |
|---|---|---|---|
| 1 | 下载与启动 | GitHub Release 下载 → Inno 安装 → 桌面快捷方式 → 自动启动 | — |
| 2 | 环境检测 | NVIDIA GPU / 驱动 / 磁盘空间；页面给进度与提示 | GPU 缺失→黄牌警告（不阻断，说明推理不可用） |
| 3 | Torch 家族下载 | 小依赖已内置安装包；启动器仅用自带 Python 从 PyTorch 官方/镜像源装 torch/torchvision/torchaudio（同源同装）；失败可换源续装 | 每包安装结果记录 |
| 4 | 依赖检验 | import torch/torchvision + 版本校验 + 关键包导入 | 通过才进下一步 |
| 5 | 模型下载引导 | 见 §5 下载规则；附直链/镜像/文件大小/放置路径 | 不阻断（允许跳过稍后再下） |
| 6 | 模型检测 | 文件存在 + 大小 + safetensors 头格式校验；提供「重新检测」 | 必装项齐 + 主模型 ≥1 通过 |
| 7 | 模拟测试 | 内置测试图经应用 API 跑一次真实修复，轮询到完成并校验输出文件 | 输出存在且非空 |
| 8 | 正式使用 | 启动 `app/clean_launch.py`；其自带 `server.auto_open_browser: true` 会自动开浏览器，引导页另留一个「点此打开 7870」的兜底链接 | — |

**每步均含"及时帮助面板"**：正在做什么 / 为什么需要 / 卡住怎么办 / FAQ 链接。

## 5. 模型下载引导规则

按"最少必要"原则，不强求下载全部：

- **必装（3 个共享文件）**：
  - `ema_vae_fp16.safetensors`（视频 VAE）
  - `pos_emb.pt` / `neg_emb.pt`（文本嵌入）
- **主模型（6 选 1）**：3b / 7b / 7b_sharp × fp16 / fp8。
  引导页按检测到的显存自动推荐（≤12GB→3B FP8；16-24GB→3B FP16 或 7B FP8；≥24GB→7B-Sharp FP16），
  并列出全部 6 个的直链、国内镜像（hf-mirror）、文件大小，供用户按需自选下载。
- **放置位置**：`{install}\model\` 根目录（与现有 `download_model.py` / `model_manager.check_model_exists` 对齐）。
- **校验**：文件存在 + 大小合理（>0 且接近预期量级）+ safetensors 头可解析。

> 模型不做自动下载（用户已明确：大文件倾向手动下载，速度更快、可复用）。

## 6. Torch 安装的幂等 / 重试 / 校验设计（关键）

针对"网络不好装失败，下次会不会重装"（仅涉及 torch 家族，小依赖已内置无需安装）：

1. **pip 幂等**：torch 家族已安装则跳过，天然安全；
2. **步骤状态文件** `.setup_state.json`：记录 torch 安装完成状态；失败后重试或下次启动**只继续未完成部分**，不从头再来；
3. **镜像切换**：PyTorch 官方源 / 国内 PyTorch 镜像（如阿里云等），一键切换后重试；
4. **同源同装**：torch / torchvision / torchaudio 必须从同一 index 一起安装，保证版本对齐（torchvision/torchaudio 与 torch 版本强绑定，不可混源）；
5. **装后必检**：第 4 步校验 `import torch` + CUDA 可用 + torch/torchvision/torchaudio 版本匹配，通过才放行；检验失败给出具体包名与修复建议。

## 7. 冒烟测试（第 7 步）

- 安装包内置一张小测试图（复用 `demo/assets/inputs/input-1.jpg` 或专门的精简测试图）；
- 通过应用 API 执行一次最小修复：上传 → 提交任务 → 轮询进度 → 校验输出文件存在且非空；
- 页面展示测试结果（成功/失败 + 用时），失败时给出排查指引并允许重测。

## 8. 错误处理汇总

| 场景 | 表现 |
|---|---|
| 无 NVIDIA GPU / 驱动过旧 | 环境检测黄牌警告，说明后果，不阻断（与现有降级模式一致） |
| 磁盘空间不足 | 检测阶段红牌阻断，给出所需空间与清理建议 |
| 依赖安装失败 | 显示错误 + 重试按钮 + 换镜像 + 手动 pip 命令兜底 |
| 模型缺失 | 引导页指引（非阻断，可稍后下载，可重测） |
| 冒烟测试失败 | 显示失败原因 + 重测；不阻断进入应用（用户可自行排查） |
| 端口占用 | 沿用现有逻辑自动找可用端口，以日志为准 |

## 9. 发布流程（CI）

扩展 `.github/workflows/gpg-signed-release.yml` 或新增 workflow，tag 触发：

1. `windows-latest` runner：`pip install pyinstaller` → 构建 `SeedVR2.exe`
2. 准备便携 Python + 应用本体 + 启动器；**构建时用便携 Python 预装全部小依赖（torch 家族除外）** → `ISCC` 编译 `SeedVR2-Setup-<ver>.exe`
3. 复用现有 GPG 签名逻辑生成 `SHA256SUMS` / `SHA256SUMS.gpg`
4. 上传三个附件到 Release

附件清单：`SeedVR2-Setup-<ver>.exe`、`SHA256SUMS`、`SHA256SUMS.gpg`

## 10. 明确不做（v1 范围外）

- 自动更新机制
- macOS / Linux 安装包
- 模型自动下载（用户明确手动）
- 安装界面多语言
- 修改任何现有 `app/` 代码

## 11. 验收标准

1. 新手从 GitHub Release 下载单个 exe，全程无需安装 Python / 无需命令行；
2. 双击桌面快捷方式，浏览器自动打开引导页并逐步完成 8 步流程；
3. 小依赖随安装包内置；torch 家族安装失败后重试/重启不重复下载已装部分；
4. 模型引导明确"必装 3 项 + 主模型 6 选 1"，检测通过才放行；
5. 冒烟测试用内置图跑通一次真实修复并校验输出；
6. 全部就绪后自动跳转 `http://127.0.0.1:7870`；
7. 现有 `app/` 代码零改动，仓库测试全绿。
